# lipu toki

Portable Windows releases by shimodatami.

This repository contains distribution documentation and signed application releases only. Application source is maintained separately.

Download lipuToki.exe into a folder you can write to. Keep your existing settings beside the application. Update metadata is authenticated by the public key pinned in the application. Consumers do not need a GitHub account or token.

Initial releases support isolated updater acceptance testing; production publication is subject to independent review.
